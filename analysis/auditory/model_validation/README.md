# analysis/auditory/model_validation/

The value model of Experiment 2: a model-free design analysis, the latent regressors of the model, recovery on simulated mice, and the Bayesian fits (PyMC).

| File | Read it when |
|---|---|
| [`QUICKGUIDE.md`](QUICKGUIDE.md) | You want to understand or run the analysis. It is also on the site: [The value model of Experiment 2](https://maravalllab.github.io/aMAZEing-maze/analysis/model-validation/). |
| [`REPORT_significance.md`](REPORT_significance.md) | You want a plain-language walkthrough of what each part of the analysis found, written for experimentalists, with the numbers as they stood when it was built |
| `HANDOFF.md` | Internal working notes from building the analysis. Not documentation, and not kept up to date. |

For the commands behind the thesis figures, see [Reproduce the thesis](https://maravalllab.github.io/aMAZEing-maze/analysis/reproduce-thesis/#running-the-value-model).

The `exp2_*` scripts one folder up read this package (its data loading, exclusions and features) but never change it or its outputs.
